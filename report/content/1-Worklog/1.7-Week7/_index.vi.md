# Tuần 7: Triển khai Tích hợp Rekognition & Transcribe

### Công việc đã làm:
- Viết code Lambda gọi Rekognition cho ảnh và Transcribe cho audio/video
- Nghiên cứu tài liệu kĩ thuật AWS Documentation liên quan đến dự án AgentSys.
- Báo cáo tiến độ hàng tuần với Mentor hướng dẫn.

### Kết quả đạt được:
- Trích xuất tự động metadata từ nhiều định dạng file (JPG, PNG, MP3, MP4)
- Tích lũy kiến thức thực tế về vận hành ứng dụng Cloud Serverless.
